# 第七阶段用户验收清单

## 打开地址

[打开帮我改简历](file:///Users/apple/Documents/Career-Agent/app/index.html#/resume/revise)

无需启动服务。先按「页面操作」完成验收；若要学习实现，再看文末「技术学习」提示。

## 验收方式

每一步请记录三件事：点了什么、页面出现了什么、是否符合「确认」说明。异常时先停在当前页截图或记下文字再反馈。

本清单中的「待用户亲测」项即使自动测试已通过，仍需你亲自操作一遍。

## 一、未配置时不能假成功（待用户亲测）

1. 打开 `#/resume/revise`，选一个有简历正文的岗位（如 job_001）。**应该看到：**准备步有「模型配置」区域，状态接近「未配置」，并提到 DeepSeek。
2. 勾选「我确认可以按上述范围发送…」，点「下一步：生成建议」。**应该看到：**生成步写明尚未接入真实 AI；「向模型请求建议」不可点。
3. 确认页面没有「已收到模型返回」之类成功说法。**说明：**没配密钥时不会伪装真实生成。
4. 点「改用本地演示建议（非真实 AI）」。**应该看到：**进入检查步，并标明不是真实 AI。

## 二、会话配置与清除（待用户亲测）

1. 返回准备步。在配置区选择 DeepSeek，确认默认服务地址含 `api.deepseek.com`、模型为 `deepseek-chat`（或你可改的名称）。
2. 粘贴**你自己的** API Key（不要发到聊天、不要提交仓库）。点「保存到本会话」。**应该看到：**状态变为「已配置待验证」；密钥只显示遮罩片段。
3. （可选）点「验证连接」。**应该看到：**成功则「验证成功」；失败则「验证失败」并提示检查密钥／网络。验证不会发送简历正文。
4. 点「清除配置」。**应该看到：**回到「未配置」；生成按钮再次不可用（除非再用演示建议）。
5. 刷新整页后再打开改简历。**应该看到：**配置默认已清除（除非你又在控制台注入）。

## 三、真实生成前确认（有密钥时，待用户亲测）

1. 重新保存并（建议）验证配置。
2. 阅读准备步「将发送给模型的内容范围」：岗位、JD、简历字数、是否外发。勾选确认后进入生成步。
3. 在生成步再次确认：模型名称、验证状态、外发／费用提醒。
4. 点「向模型请求建议」。**应该看到：**进度经历准备中／请求中，然后成功进入逐条建议，或失败并保留原简历与草稿。
5. 失败时点「重试生成」或改用本地演示。**确认：**原稿正文未被清空。

## 四、成功后的检查与保存（可用演示建议代替真实模型）

1. 对若干条建议分别「采纳」「跳过」或「改写后采纳」。
2. 点「保存为新草稿」。**应该看到：**保存成功提示；原「我的简历」正文不变。
3. 只有点「使用此简历」才进入确认／准备材料路径。

## 五、安全底线（务必确认）

- 页面、截图、本地业务存储里看不到完整 API Key。
- 未配置时没有「生成成功」误导。
- 失败或清除配置后，原简历与已保存岗位草稿仍在。

## 需要你提供／决定的事项

1. 是否在本机临时使用 DeepSeek Key 做真实调用（可跳过，交付已标「真实调用未验证」）。
2. 是否允许把当前演示简历正文发往外部模型。
3. 生成建议的语气与岗位对齐是否够用。
