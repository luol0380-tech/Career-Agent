# Career Agent｜演示闭环脚本（Demo Beta）

日期：2026-10-01。入口：`file:///Users/apple/Documents/Career-Agent/app/index.html`（无需服务）。数据为合成演示；保存仅在本浏览器本地。

## 开场说明（30 秒）

1. 打开首页，指出顶栏「合成演示数据｜Demo Beta」与「当前浏览器本地（不同步云端）」。
2. 说明：**不是**真实自动投递、**不是**已验证的真实 AI（未配密钥时不会假成功）。

## 路径 A：简历 → 按岗位改 → 保存草稿

1. 首页 →「上传 PDF 简历」或「打开我的简历」→ 粘贴／保存正文。
2. 「帮我改简历」→ 选岗位 → 准备步可读发送范围。
3. **无密钥**：勾选确认 →「本地演示建议」→ 采纳一条 →「保存为新草稿」→ 确认原简历未改。
4. **有 DeepSeek Key（可选，勿展示完整密钥）**：保存到本会话 → 验证连接 → 生成 → 检查失败／成功表现 →「清除配置」。

待亲测：`docs/PHASE7_USER_ACCEPTANCE.md`。

## 路径 B：准备材料 → 记录外部投递／结果

1. 岗位详情 →「准备投递材料」→ 编辑并保存版本（不可覆盖旧版）。
2. 「记录已投递」（仅外部已投时）→ 指标「已投递」变化。
3. 「记录投递结果」：Offer／拒绝／退出／接受 → 强调**记录外部结果**。
4. 终态页只读，不能改回进行中。

待亲测：`docs/PHASE8_USER_ACCEPTANCE.md`。

## 路径 C：面试改期／取消

1. 助手「我想改期或取消面试」或打开 `#/interview/interview_002`。
2. 改期保存 → 仍同一轮。
3. 取消本轮 → 投递状态按规则回退（样例二面取消后为「面试已完成」）。

待亲测：`docs/PHASE9_USER_ACCEPTANCE.md`。
