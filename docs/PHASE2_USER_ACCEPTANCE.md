## 本轮请重点测试

### 1. 准备投递与文档工作区

1. 打开“岗位工作区”。
2. 进入任意岗位详情，点击“准备投递”。
3. 点击“开始准备投递”。
4. 检查是否出现基础简历、定制简历、自我介绍、开场沟通材料。
5. 修改一份材料正文，点击“保存为新版本”。
6. 再修改一次并保存，确认出现两个独立版本，旧版本内容没有被覆盖。

### 2. 文档草稿保护【重点】

1. 在材料正文中输入一段容易识别的文字，但不要保存。
2. 点击左侧导航或浏览器后退。
3. 确认出现“继续编辑／放弃修改并离开”。
4. 点击“继续编辑”，确认文字仍在。
5. 再次离开并选择“放弃修改并离开”，确认页面正常离开。
6. 刷新页面，确认未保存正文不会被伪装成已保存版本。

### 3. 记录已投递

1. 在准备中的投递区域点击“记录已投递”。
2. 填写投递发生时间。
3. 选择一个已确认的材料版本，提交记录。
4. 确认状态变为“已投递”，并显示具体材料版本。
5. 确认页面没有把“准备材料”说成“已经自动投递”。

### 4. 面试记录与复盘【重点】

1. 从岗位详情进入“面试记录”。
2. 登记第一轮面试，可不填写具体时间。
3. 再登记第二轮，确认不会覆盖第一轮。
4. 打开一轮面试，输入用户笔记并保存。
5. 确认复盘区域显示“尚未分析”，没有自动编造结论。
6. 打开预置面试，确认预置内容明确标记为“演示预置”。

### 5. 求职进展二级页

从“求职进展”依次打开：

- 已分析岗位
- 已投递
- HR 回复
- 面试次数
- 面试复盘

确认列表只显示当前目标的数据，并且可以返回原岗位或面试上下文。

## 当前已知限制

- 仍是本地合成演示数据，不接入真实 AI、上传、云端同步或自动投递。
- 当前仅验证 Chrome；Safari、Firefox 和真实读屏尚未验证。
- 若浏览器打开页面长时间空白，先刷新一次；不要启动项目服务。
