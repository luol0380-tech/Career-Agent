## 一、改期（待用户亲测）

1. 确认本轮状态为已排期。**应该看到：**「改期／确认时间」。
2. 填写新时间，点「保存改期」。**应该看到：**排期时间已更新；仍是同一轮，没有多出一轮。

## 二、取消（待用户亲测）

1. 点「确认取消本轮」（可填原因）。**应该看到：**本轮变为已取消。
2. 确认关联投递状态变为「面试已完成」（因为一面已完成）。**说明：**没有未完成轮次时按契约回退。
