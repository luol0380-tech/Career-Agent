# 第八阶段用户验收清单

## 打开地址

[打开准备投递材料（岗位一）](file:///Users/apple/Documents/Career-Agent/app/index.html#/prepare?job=job_001&goal=goal_ai_pm)

无需启动服务。每步记录：点了什么、看到什么、是否符合确认说明。

## 一、准备中退出（待用户亲测）

1. 打开岗位一准备材料页。**应该看到：**投递状态为「准备投递」。
2. 在「记录投递结果」选「我退出投递」，填写发生时间，可选填原因，点确认。**应该看到：**状态变为「已退出」。
3. 确认没有出现「已记录投递」时间。**说明：**退出不会伪装成已投递。

## 二、记录 Offer 与接受（待用户亲测）

1. 可用「重置演示」恢复样例后，打开岗位二准备材料（job_002）。
2. 选「收到 Offer」，填时间并确认。**应该看到：**状态「已收到 Offer」；未完成面试变为已取消。
3. 再选「接受 Offer」并确认。**应该看到：**状态「已接受 Offer」；页面说明流程已结束，不能再改态。

## 三、拒绝（可选）

1. 重置后打开目标二岗位三（job_003），选「被拒绝」并确认。**应该看到：**状态「已被拒绝」。

## 四、最重要的判断

- 页面是否清楚在「记录外部已发生的结果」，而不是自动投递？
- 结束后是否还能误点改回进行中？（不应能）
