# 架构与 V1 范围

契约版本：`0.1`；初稿日期：2026-09-28；更新日期：2026-09-29。此版本服务当前施工，不代表所有后续模块已经实现。

## 产品与边界

产品定位为 AI 求职工作台。闭环为：职业资产 → 求职目标 → 岗位判断 → 求职文档 → 投递跟进 → 面试准备／复盘 → 下一步行动。

保留六层设计，但以一个应用内的职责边界落地：

| 逻辑层 | V1 实现方式 |
| --- | --- |
| Infrastructure | 第一阶段浏览器、本地演示存储；后续真实服务独立决策 |
| Data / Object | 统一实体、版本与数据适配接口 |
| Agent / State Machine | 第一阶段只约定契约，后续用显式业务操作和转换表控制流程 |
| Skills | 按用例组织普通函数和可替换生成能力，不建通用插件平台 |
| Product Stage | 由当前目标／岗位／投递上下文解释出的阶段，不是用户唯一全局状态 |
| Frontend Workbench | 页面、组件与路由，只调用数据入口，不自行发明业务规则 |

来源与版本、评测与记录、隐私与权限贯穿以上模块，不各建一套服务。

## 业务操作边界

明确按钮直接触发业务操作；自由文本才需要候选意图识别。Supervisor 及四个 Orchestrator 暂为未来职责划分，不为其建设四个相互对话的 Agent。

业务链路：原始输入 → 候选解释 → 校验／必要时确认 → 业务命令 → 同次提交保存业务事件和对象变化 → 生成任务／待办 → 页面反馈。

- 原始文本是用户输入记录，不能自动成为已确认的业务事实。
- 状态更新、事件持久化、引用校验、去重由确定性程序执行。
- AI 仅提供提取候选、证据选择和表达草稿；写入要通过同一业务入口。
- 未来真实数据库中事件和业务对象使用事务；生成失败不回滚已确认的现实变化。
- 不为 V1 引入消息队列、微服务、向量库或完整 Event Sourcing。

## 三个交付阶段

1. **前端第一阶段**：App Shell、Home、Vault、Job；合成数据、基本编辑、目标切换、持久化与状态展示。
2. **完整演示闭环**：Document、Application、Interview、Goal 基本编辑、Quick Capture 手动记录、四项首页指标。
3. **条件性真实能力**：闭环与发布无阻塞时，接“已确认资产＋岗位 → 文档草稿 → 用户修改 → 版本保存”一条真实能力。

第二阶段仍允许用明确标注的预置分析演示。新输入没有真实分析时，只保存文本并说明“尚未分析”，不能展示与输入无关的固定结果冒充分析。

## 必保与延后

Document 为 P0：基础／定制简历；30 秒／1 分钟／2 分钟自我介绍；Boss／猎头／内推／HR 开场白；面试准备文档。共用编辑器，参数选择，不分别开发独立页面。

文档 P0 支持编辑、保存不可变版本、复制。模板排版、PDF／DOCX 导出、富文本平台可延后。

延后：岗位爬取、自动投递、浏览器 Agent、邮件／日历同步、飞书／Notion 深度连接、音频转写、实时模拟面试、独立复杂 Insights。

真实用户 Beta 需要身份验证、用户隔离、服务端存储和删除能力，必须单独评估，不用公开演示 Beta 替代其验收。

## 当前技术约定

第一阶段按用户空项目偏好采用 HTML、原生 JavaScript、Tailwind CDN 和 Font Awesome。采用普通延迟加载脚本及显式命名空间，以便直接打开 `app/index.html` 验收；不依赖 file:// 下的 fetch 或 ES Module。Mock fixture 使用 JavaScript 数据文件。

不安装框架、不加入 npm 构建链。未来确需迁移时先记录具体原因、成本和边界，再评审。CDN 仅用于样式和图标；页面应保留基础可读布局及资源失败提示。

推荐目录：

```text
app/
  index.html
  styles.css
  main.js
  domain/       # 字段校验、状态常量和纯计算
  data/         # 统一数据接口、localStorage 演示适配
  fixtures/     # 不可变的合成初始数据
  features/     # home、vault、jobs 等视图与业务交互
  components/   # shell、导航、通用交互
```

页面调用统一异步数据接口，Mock 和未来真实实现保持相同输入输出。将业务快照与操作事件保存为一个带 schemaVersion 的演示状态包；持久化失败时保留旧状态并提示，禁止假装保存成功。

启动时存储不可用则进入只读临时浏览，不接受仅内存的业务提交；损坏或版本不兼容的数据保留原串，经用户明确确认后才能重置。运行中单次保存失败继续保留草稿和旧状态，不自动降级。详细行为以数据契约为准。
