# 第三阶段用户验收清单

## 打开地址

[打开职业求职助手](file:///Users/apple/Documents/Career-Agent/app/index.html#/home)

无需启动服务。先按“页面操作”完成验收；如果你要逐帧学习，再看每一步后面的“技术学习”说明，里面会指出代码位置、数据变化和验证方法。

## 验收方式

请按步骤逐条操作，不要一次跳过多步。每一步都看三件事：

1. **我点击了什么**：记录按钮或入口的文字。
2. **页面发生了什么**：记录出现的文字、状态或页面变化。
3. **这是否符合预期**：对照本清单中的“确认”说明判断。

如果某一步没有看到预期结果，先停在当前页面截图或记下文字，再反馈问题，不需要自己查看代码或猜测原因。

## 一、首页入口

打开首页后，首屏应能直接看到：

- 上传 PDF 简历
- 我的简历
- 开始整理求职材料
- 求职助手帮我指路

如果需要滚动或进入岗位详情才能找到上传入口，就记为问题。

## 二、上传 PDF

1. 点击“上传 PDF 简历”。**应该看到：**系统打开文件选择窗口。
2. 选择一份本地 PDF 文件。**应该看到：**页面回到简历区域。
3. 确认页面显示文件名和文件大小。**说明：**系统知道你选了哪份文件。
4. 确认状态显示“待确认”，不要显示“已确认”。**说明：**系统在等你确认内容。
5. 打开“我的简历”，确认能看到这份材料。**说明：**上传后的材料有固定入口。

## 三、查看和修改简历

1. 点击“我的简历”。**应该看到：**当前简历和它的状态。
2. 点击“查看内容”或进入正文编辑区域。**应该看到：**可以阅读或修改的正文。
3. 粘贴一小段测试文字，例如“这是我的简历测试内容”。**应该看到：**文字出现在正文中。
4. 点击保存正文。**应该看到：**页面提示保存成功。
5. 确认保存后内容仍在。**说明：**刚才的修改没有丢失。
6. 点击“确认这份简历内容”。**应该看到：**确认操作完成。
7. 确认状态从“待确认”变成“已确认”。**说明：**之后才可以把它作为已确认材料使用。

## 四、重新上传失败保护

1. 先确认已有一份简历处于可查看状态。
2. 点击“重新上传”。
3. 取消文件选择，或选择非 PDF 文件。
4. 确认页面显示失败或取消提示。
5. 确认上一份简历仍然存在，没有被清空。

## 五、历史材料

1. 上传或保存第二次内容。
2. 打开历史列表。
3. 确认之前的材料仍可以查看。
4. 确认新材料没有静默覆盖旧材料。

## 六、求职助手

1. 点击“求职助手帮我指路”。**应该看到：**几个明确的下一步选项。
2. 逐个阅读选项，不需要输入复杂问题。**说明：**这是一个引导入口。
3. 点击“上传简历”“修改简历”“查看岗位”“记录面试”等选项。**应该看到：**页面开始进入对应任务。
4. 确认每个选项都进入对应页面。**说明：**每个建议都能实际执行。
5. 确认页面没有把它描述成已经接入真实 AI 的聊天机器人。**说明：**当前是清晰的功能引导。

## 七、最重要的判断

验收时请重点判断：

- 我能不能一眼找到下一步？
- 我能不能明确知道简历现在是什么状态？
- 我能不能找到查看、修改和重新上传的位置？
- 上传失败后，之前的简历是否还在？
- 页面有没有把系统内部术语直接丢给我？

反馈格式：

`通过：第 1、2、3 项`

或：

`问题：第几项；我点击了什么；实际看到什么；我期望看到什么。`
